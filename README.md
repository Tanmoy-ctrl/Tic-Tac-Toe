# Tic-Tac-Toe

A simple command-line Tic-Tac-Toe game developed using Python.

## Features

* Two-player gameplay
* Simple command-line interface
* Players take turns placing `X` and `O`
* Checks for winning conditions
* Detects a draw

## Technologies Used

* Python

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python main.py
```

## How to Play

* Player 1 uses `X`.
* Player 2 uses `O`.
* Enter the position where you want to place your symbol.
* The first player to get three symbols in a row wins.

## Project Purpose

This project was created to practice Python programming, conditional statements, loops, functions, and basic game logic.
